# 02. Среда моделирования: описание модулей (индекс)

Описание шести модулей каталога `src/ssn_hops/`, которые задают конфигурацию, геометрию созвездия, контакты, графы и трафик: `config.py`, `sim_config.py`, `geometry.py`, `contacts.py`, `graph.py`, `traffic.py`. Документ разбит на части из-за ограничения размера записи. Этот файл — индекс; описание продолжается в файлах `02_ENVIRONMENT_RU_part1.md` … `02_ENVIRONMENT_RU_part8.md` (в той же папке `docs/`). Документ заканчивается списком «Не установлено чтением» (часть 8, раздел 9).

## Части

| Часть | Файл | Содержание |
|---|---|---|
| 1 | `02_ENVIRONMENT_RU_part1.md` | `config.py`: назначение, константы, функции проверки чисел, `OrbitConfig`, `DataConfig` |
| 2 | `02_ENVIRONMENT_RU_part2.md` | `config.py`: `ModelConfig` (режимы признаков), `TrainConfig`, `Config`, загрузка и миграция |
| 3 | `02_ENVIRONMENT_RU_part3.md` | `sim_config.py`: `SimulationConfig`, `ticks`, `service_ticks`, правило повтора, лимит хопов |
| 4 | `02_ENVIRONMENT_RU_part4.md` | `geometry.py`: система координат, положения, случайная траектория, видимость и смежность |
| 5 | `02_ENVIRONMENT_RU_part5.md` | `contacts.py`: `GeometryNetwork`, план контактов, `earliest_hop`, `build_geometric_plan` |
| 6 | `02_ENVIRONMENT_RU_part6.md` | `graph.py`: метки хопов, структура «1 / 0.5 / 0», входы ветвей сети |
| 7 | `02_ENVIRONMENT_RU_part7.md` | `traffic.py`: трасса пакетов, документ трассы, испытания отказа передачи |
| 8 | `02_ENVIRONMENT_RU_part8.md` | сводные ответы (параметры среды, случайность, валидация), наблюдения, список «Не установлено чтением» |

## Условные обозначения
- «В коде написано» — пересказ или цитата текста исходного файла. «Вывод из чтения» — заключение, сделанное при чтении текста без запуска. «Ручной расчёт» — арифметика, выполненная вручную и показанная в тексте.
- Ничего из описанного не запускалось: нет заявлений о том, что код работает, прошёл тесты или даёт какие-либо результаты. Результаты экспериментов в документе не приводятся.
- Идентификаторы, имена файлов и параметров даны латиницей. Номера строк не приводятся; ссылки даются как «файл, класс/функция/константа».
- Комментарии и строки самого кода местами называют внутренние документы, тесты и метки задач (например, `T022`, `T054`, `T056`, путь `Repo_Code_2/artifacts/T056/S02_CHANGED_PATHS.md`, тест `tests/reference/contacts_ref.py`). Эти документы и тесты не входят в экспорт; в описании они упомянуты только как цитаты кода.

## Зависимости между шестью модулями (по строкам `import`)
```
config.py        — без внутренних импортов (стандартная библиотека)
sim_config.py    ← config
traffic.py       ← config, sim_config
geometry.py      ← config                (numpy)
contacts.py      ← config, geometry, sim_config   (numpy)
graph.py         ← config, features              (numpy, torch)
```
`features.py` в эту часть не входит; из него использованы только `validate_adjacency`, `validate_ranges`, `delay_features` (часть 6). Сторонние пакеты: `numpy` (geometry, contacts, graph), `torch` (graph). `config.py`, `sim_config.py`, `traffic.py` сторонних пакетов не требуют.

## Как читать
Начните с части 8 (сводка параметров и случайности), затем обращайтесь к частям 1–7 за подробностями по модулю. Каждая часть содержит разделы: назначение; входы и выходы; классы и функции; значения по умолчанию; связи с другими модулями; побочные эффекты; допущения и реконструкция, названные в коде; что не установлено чтением.
