## 4. Где наши направления отличаются от статьи (запись исследования)
Источник: запись исследования о направлениях рис. 3–5 (значения статьи — оценка на глаз, ±0,1–0,3 с; наши — из запуска ревизии 3a, старый объём, среднее по пяти сценариям, CGR три и только при N = 132; числа перенесены в запись вручную, файл без рецензии; пересчёт разностей в записи — ручной расчёт). Рисунки в ревизии 5 не строились никем.
- **Рис. 3(a), задержка против p (N = 132).** Статья: все четыре кривые растут. У нас: CGR растёт (8,60 → 11,22 с) — совпадает; GLR убывает (22,42 → 12,60) и TBR немонотонно убывает (11,37 → 10,08) — противоположно; TSR растёт до p = 0,03 (38,06), дальше снижается — частично. GLR ниже TBR при p ≥ 2 % в статье, у нас выше при каждом p — противоположно. Наибольшая у TSR при каждом p — совпадает при p ≥ 3 % (в статье при 0 и 1 % худший CGR).
- **Рис. 3(b), потеря против p.** Статья: TSR наибольшая (0,5 → 1,6 %), GLR не выше 0,15 %. У нас доля отказов GLR 0,0040 → 0,5543 (0,4 % → 55,43 %, ручной расчёт ×100): на порядки больше; TSR наибольшая только при p ≤ 0,04, при p ≥ 0,05 наибольшая у GLR.
- **Рис. 4, задержка против N (p = 4 %).** Статья: у всех снижение с N, GLR самый низкий, разрыв TBR − GLR сужается (0,70 → 0,15 с по описанию рисунка). У нас (N = 132…330): TBR и TSR снижаются — совпадает; GLR в целом снижается (17,78 → 15,90); ниже всех TBR, а не GLR — противоположно; разрыв GLR − TBR 6,81; 6,36; 6,61; 7,23 с (ручной расчёт записи), не сужается — противоположно; TSR наибольшая — совпадает. - **Рис. 5, затраты.** Растут с N у обоих — совпадает. Статья: GLR дешевле TBR (≈ 6,1 раза при N = 132, ≈ 37,9 раза при N = 396); у нас GLR дороже BFS-TBR (1,68 раза при N = 132, 8,7 раза при N = 330; ручной расчёт записи); единица статьи неизвестна, наш TBR — не перебор: порядок не сопоставим.

## 5. Чем отличаются шесть рисунков `plot_summary` от этого набора
Шесть рисунков делает стадия `plot` run_all.py (`plot_summary`, папка `<папка>/plots/`; описание — docs/05, часть D, в этом шаге не перечитывалось).
| | `plot_summary` | `paper_style_plots.py` |
|---|---|---|
| число | по одному на (сетка, вариант, метрика): оси p — задержка, `failure_fraction`, `pending_fraction`; оси n — задержка, `route_seconds_per_call`, `simulation_seconds`; для двух бакетов 2 × 3 = 6 (ручной расчёт) | до шести заданий, каждое в двух файлах |
| вид | только линии с маркером `o`, цвета matplotlib по умолчанию, 10 × 6 дюймов | линии (рис. 3, 5) и столбики (рис. 4) в цветах и штриховках рис. 4, 8,0 × 6,6 дюйма |
| ошибки | SE у каждой точки всегда | в отдельных файлах `_se` |
| единицы | p и доли как есть (доли 0…1) | p и потеря в процентах |
| оси | «Per-active-transfer-tick abort probability p», «Constellation size N» | «Interruption probability (%)», «Network scale» |
| заголовок | «RECONSTRUCTION / NOT AUTHORS' RESULTS» + сетка / вариант / режим + dt, rate, load | «Reconstruction, not the authors' results» + подзаголовок |
| только здесь | `pending_fraction`, `simulation_seconds`, `plot_data.json`, `complete.json` с хешами | потеря против N, логарифмическая ось затрат, демо |
| папка и проверки | `mkdir(exist_ok=False)`; хеш сводки сверяется до и после | пустая или новая папка; хеш не сверяется (передаётся `None`) |
Оба используют одну и ту же `prepare_plot_data`, поэтому данные и их проверка общие (вывод из чтения).
