# 01. Архитектура системы целиком (индекс)

Документ описывает всю систему на одном уровне: слои, зависимости модулей, сквозной поток данных, модель времени, случайность, политики маршрутизации и строки схем, связывающие слои. Текст разбит на три части в той же папке `docs/`; этот файл — индекс. Подробности по отдельным модулям — в группах 02-06 (`02_ENVIRONMENT_RU.md`, `03_LEARNING_RU.md`, `04_SIMULATION_POLICIES_RU.md`, `05_EXPERIMENTS_RU.md`, `06_CONFIGS_SUITES_RU.md`). Точка входа для читателя — `README.md` в корне экспорта.

## Части

| Часть | Файл | Содержание |
|---|---|---|
| 1 | `01_ARCHITECTURE_RU_part1.md` | разделы 1-3: слои (среда, обучение, симуляция и политики, эксперименты, драйвер, конфигурации); таблица зависимостей по строкам `import` (11 модулей проверено по коду, остальные — по индексам); выводы о графе импортов |
| 2 | `01_ARCHITECTURE_RU_part2.md` | разделы 4-8: стадии сквозного потока данных с файлами на входе и выходе; конвейер `plan` / `train` / `execute`; диаграмма Mermaid; расписание срезов драйвера и ручной расчёт 50 сценариев и 162 ячеек; поправка к части 1 |
| 3 | `01_ARCHITECTURE_RU_part3.md` | разделы 9-13: модель времени (тик, хоп, TTL, правило повтора, порядок событий в тике); где входит случайность; таблица политик; файлы и строки схем; поправки и не установленное чтением |

Порядок чтения: 1, 2, 3.

## Условные обозначения

- «В коде написано» — пересказ или цитата кода; «вывод из чтения» — заключение без запуска; «ручной расчёт» — арифметика, показанная в тексте.
- Ничего не запускалось: в документе нет утверждений, что код работает, прошёл тесты или даёт результаты. Результатов экспериментов нет.
- Модули, чьи строки `import` прочитаны в самом коде при подготовке документа: `sim_config`, `traffic`, `graph`, `provenance`, `cli`, `policies`, `simulator`, `tbr_policy`, `simulate` (пакет `ssn_hops`), `plan_io`, `ledger` (драйвер). Времена, горизонты, TTL и правило повтора сверены с `sim_config.py` и `simulator.py`.
- Документы, которые код называет в строках и которых нет в экспорте, помечены как «не входит в экспорт».

## Что в документе важно знать сразу

- Все значения времени — в тиках по `tick_s = 0.1` с: горизонт 9000 тиков, TTL 3000 тиков, передача пакета в 18000 байт при скорости 12500 байт/с занимает 15 тиков при умолчаниях (часть 3, раздел 9).
- Слои не образуют жёсткой иерархии по импортам: `graph.py` импортирует `features.py` (часть 2, раздел 8).
- Суммарного ограничения минут в драйвере нет (часть 2, раздел 7; `README.md`, раздел 6).
- Ограничения реконструкции и перечень неустановленного по всей системе — в `docs/07_LIMITATIONS_RU.md`, оговорки и наблюдения — в `docs/ERRATA_RU.md`.
